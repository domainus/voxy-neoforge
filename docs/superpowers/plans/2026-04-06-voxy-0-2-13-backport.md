# Voxy 0.2.13 Backport Implementation Plan

> **For agentic workers:** REQUIRED: Use superpowers:subagent-driven-development (if subagents available) or superpowers:executing-plans to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Backport upstream Voxy `0.2.10-alpha` through `0.2.13-alpha` changes into this NeoForge `1.21.1` port and then reapply the local NeoForge, Embeddium, and Iris/Monocle compatibility layer so the project builds on NeoForge again.

**Architecture:** Treat upstream Fabric `0.2.13-alpha` as the semantic source for shared Voxy code, but keep all NeoForge loader, metadata, and platform glue local. Import upstream behavior in logical batches, then reconcile compatibility-sensitive rendering and mixin code on top.

**Tech Stack:** Java 21, NeoForge 21.1.115, Minecraft 1.21.1, Embeddium 1.0.15, Iris 1.8.12 via Monocle, Gradle.
